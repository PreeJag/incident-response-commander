# Incident Commander AI

Create a professional enterprise cybersecurity web application called "Incident Response Commander".

Purpose:

Help security teams respond to cyber incidents using AI.

Pages:

1. Home

- Hero section

- Description

- Start Analysis button

2. Incident Analysis Page

- Incident Type dropdown:

  - Phishing

  - Malware

  - Ransomware

  - Data Breach

  - DDoS

  - Insider Threat

- Organization Size dropdown:

  - Small

  - Medium

  - Enterprise

- Incident Description textarea

- Analyze Incident button

3. Results Page

Display cards for:

- Severity Level

- Risk Score

- Immediate Actions

- Containment Plan

- Eradication Plan

- Recovery Plan

- Executive Summary

- Lessons Learned

Design Style:

IBM inspired

Modern enterprise dashboard

Blue and white

Minimal

Professional

Responsive
